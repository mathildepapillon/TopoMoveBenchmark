# Known gaps in figure inputs

- `chemistry_case_studies.pdf`: the frozen record (`molecules_data.json`) carries no element labels for Mutagenicity (`element_labels: false`, empty `el` fields), so atoms in that panel are drawn without element letters.
- `estimator_variance.pdf`: no frozen file records attribution-value-space error (per-player Shapley-value error vs. the exact game, e.g. MAE/RMSE or rank correlation) as a function of pass budget. Looked for such fields in `data/frozen/cheap_sim12.json` (`per_dataset[ds].per_seed[seed].permutation[budget]` carries only `mean_n_perms`, `mean_passes_used`, and `per_k.{agreement, mean_cheap_regret, picks}`) and in `data/frozen/analysis12.json` (`estimator_validation_6space` sweeps sweep-size N — `pool_style` vs `exact_at_grid` — not permutation passes). The figure therefore shows the frozen selection-level error that does exist per pass budget: the cheap-value regret of sampled-game picks vs. the exact-game selection (the quantity behind `\ResRegretMax`), for budgets {32, 64, 128, 256, 512} x 3 seeds x k in {2, 3, 6}. Pick-agreement per budget is also frozen but not plotted.

- `exhaustive_landscape.pdf`: no PROTEINS panel — `pooled.json:retraining_pooled` has no `PROTEINS` key (excluded a priori with no landscape; see `pooled.json:sensitivity.endpoint_gate_interior_contrast.datasets_without_a_landscape`). The figure shows the 12 enumerated landscapes.
