\section{Trustworthiness: Axioms as Executable Checks}
\label{sec:trustworthiness}

\expclaim{Because exact Shapley computation satisfies efficiency,
null-player, and symmetry as machine-checkable equalities, running
\method doubles as an integration test of the model stack, and those
checks caught \unfrozen{\ResNumBugsFramework} real bugs in the
TopoBench framework, plus a composed cross-rank batching bug caught by
an invariance guard (\unfrozen{\ResNumBugsTotal} total).} Efficiency
requires attributions to sum exactly to the prediction gap; null
players (a masked cell, a disconnected submodule) must receive exactly
zero; symmetric players equal credit; and attributions must be
invariant to batching and cell ordering. Each is a finite computation
with an exact expected value, so any violation is a bug, never a
matter of interpretation. The catches (dead inter-rank routes,
a batch-dependent collapsed backbone, rank-aliasing feature offsets,
and the composed batching bug) were each independently confirmed and
reported upstream (reproductions in \cref{app:trust-details}); an
accuracy table cannot distinguish a model that ignores a neighborhood
by choice from one whose route is dead, and every fix strengthens the
shared stack. The same posture catches metric failures: a sanity
check against class-imbalanced MANTRA's majority rate flagged
\unfrozen{\ResMantraCollapsedModels} plain-accuracy cells as
byte-identical collapses; every MANTRA comparison in
\cref{sec:performance} is balanced accuracy (\cref{app:coverage}).
The checks also police our own method: the one failure
mechanism we found (substitute-commitment, Proposition~T1) replicates
in a second architecture family with different components, yet every
catastrophic pick observed anywhere in this project was
validation-visible before it could reach a result, which is why the
pipeline decides only on trained-rung validation
(\cref{app:trust-details}); the cheap game's pricing is likewise
auditable in unique coalition evaluations (\cref{app:accounting}). We
ship the checks as a standalone test suite.


\paragraph{The same guards found a data finding.}
The participation game requires that the full coalition reproduce the
stored complex bit for bit. Auditing this requirement on lifted data
exposed the feature cache of \cref{sec:predictions-higher}: standard
feature liftings store sums of boundary features inside higher-rank
cells, so a detached cell keeps testifying through its cached sum. The
observation began as a failed consistency check and became the
structural-lifting result. Guards that refuse unfaithful games pay for
themselves twice, first as software checks and then as science.
